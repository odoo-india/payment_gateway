On the main menu or sidebar, click the “Settings” option. Then, go to the “Credentials” tab, where you can find the Client ID and Client Secret, which you will later add on the Odoo side.

Check the account mode in the top right corner of the page. Use the Test mode to try the integration without charging customers. Switch to Live mode once you are ready to accept payments.

Configure Webhook
  1. Log in to your PineLabs Pluralonline Dashboard.
  2. On the main menu or sidebar, click the “Settings” option
  3. go to the webhook tab
  4. Enter your Odoo database URL followed by /payment/pinelabs/webhook in the Webhook URL field.
    For example: https://example.odoo.com/payment/pinelabs/webhook
    (Also email Pine Labs support at pgsupport@pinelabs.com to enable this webhook URL.)
  5. Enable the following events:
    • Payment Failed
    • Payment Refund Success
    • Payment Refund Failed
    • Payment Captured
    • Payment Cancelled

    6. Save the configuration to allow Pinelabs to send real-time updates to Odoo.

Configuration on Odoo

  1. Install the module from the Apps menu.
  2. Now, navigate to the Payment providers by going to:
    • Accounting ‣ Configuration ‣ Payment Providers
    • Website ‣ Configuration ‣ Payment Providers
    • Sales ‣ Configuration ‣ Payment Providers
  3. Select the provider and configure the Credentials tab.
  4. Set the State to Enabled.

After configuring the details, On your website checkout page, you will see the Pinelabs payment methods (UPI, Card, Netbanking, etc.) based on the configuration you set in the Payment Provider.
