Upon signing in into your Paytm dashboard, navigate to Developer Settings → API Keys (located on the left side of dashboard) where you would find your both Staging and Production environment credentials.

Make sure to note your Environment - use the Staging credentials for testing and switch to Production once you're ready to go live.

In order to view transactions of staging environment, you need to toggle TEST DATA on the top right corner of dashboard

Payment Gateway Access
Configure Webhook

Note for Webhooks:
Paytm merchant account must be activated in order to access webhook URL configuration.

On Paytm Merchant Dashboard, the webhook configuration in Developer settings → webhook URL points to the Production environment only. To configure webhooks for the staging environment, you must contact the Paytm support team directly to set up your webhook URL.

  1. Log in to your Paytm Merchant Dashboard.
  2. From the left side panel, click the Developer Settings option.
  3. Select Webhook URL.
  4. For both Payment Notification URL and Refund Notification URL, click Add and enter your Odoo database URL followed by /payment/paytm/webhook.
    For example: https://www.example.com/payment/paytm/webhook

Configuration on Odoo

  1. Install the module from the Apps menu.
  2. Now, navigate to the Payment providers by going to either:
    • Accounting → Configuration → Payment Providers
    • Website → Configuration → Payment Providers
    • Sales → Configuration → Payment Providers
  3. Select the provider and configure the Credentials tab.
  4. Set the State to Enabled.

After configuring the details, On your website checkout page, you will see the Paytm payment methods (UPI, Card, Netbanking, etc.) based on the configuration you have set in the Payment Provider.
