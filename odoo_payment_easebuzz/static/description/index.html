After signing in, check the account mode in the top-right corner of the dashboard.
Use Test Mode to try the integration without real charges, and switch to Live Mode when you are ready to accept payments from customers.

Configure Webhook
  1. Log in to your Easebuzz Merchant Dashboard.
  2. Go to Account Settings → Webhook .
  3. Toggle the Test Mode switch in the left menu to try the integration without charging customers.
  4. Under the "URL with your registered domain" column, enter your Odoo database URL followed by /payment/easebuzz/webhook in the Webhook URL field.
    For example: https://example.odoo.com/payment/easebuzz/webhook
  5. Enable the following events:
    • Transaction Webhook
    • Refund Webhook

    6. Save the configuration to allow Easebuzz to send real-time updates to Odoo.

Configuration on Odoo

  1. Install the module from the Apps menu.
  2. Now, navigate to the Payment providers by going to:
    • Accounting ‣ Configuration ‣ Payment Providers
    • Website ‣ Configuration ‣ Payment Providers
    • Sales ‣ Configuration ‣ Payment Providers
  3. Select the provider and configure the Credentials tab.
  4. Set the State to Enabled.

After configuring the details, On your website checkout page, you will see the Easebuzz payment methods (UPI, Card, Netbanking, etc.) based on the configuration you set in the Payment Provider.
