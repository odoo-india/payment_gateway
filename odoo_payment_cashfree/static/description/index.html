CashFree Payment Provider for Odoo

Accept Secure Payments Seamlessly with CashFree

The CashFree Payment Provider module enables you to accept online payments directly within Odoo using the popular CashFree payment gateway. This integration allows customers to make fast, secure, and convenient payments via UPI, debit/credit cards, wallets, etc.

✨ Key Features

  • ✅ Seamless integration with CashFree API
  • ✅ Supports Website/eCommerce payments
  • ✅ Secure payment and refund flow with webhook callback validation
  • ✅ Automatic order status updates upon successful payment
  • ✅ Easy configuration via Odoo Payment Providers menu
  • ✅ Works with both sandbox and production environments

🛠 Configuration Steps

  1. Go to Invoicing / Accounting → Configuration → Payment Providers.
  2. Create or select the CashFree provider.
  3. Enter your Client Id and Client Secret.
  4. Choose the appropriate environment (Sandbox or Production).
  5. Set webhook URLs in the CashFree dashboard to match the module endpoints (e.g. {{YOUR DOMAIN}}/payment/cashfree/webhook).

💼 Compatibility

  • ✅ Compatible with Odoo 19.0 and above
  • ✅ Supports both Community and Enterprise editions
  • ✅ Fully tested with payment flows
