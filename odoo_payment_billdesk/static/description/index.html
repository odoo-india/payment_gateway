Configure Webhook
  1. Contact Billdesk Onboarding Team through mail and mention the below webhook url for whitelisting.
  2. Webhook url will be your Odoo database URL followed by /payment/billdesk/webhook in the Webhook URL field.
    For example: https://example.odoo.com/payment/billdesk/webhook

    3. After successfully configuring the webhook BillDesk will send real-time updates to Odoo.

Refund API

    The Refund API is disabled by default in BillDesk. To make sure you can refund through Odoo follow below steps:

  1. Contact Billdesk Onboarding Team to enable refund api for your credentials.
  2. Once, refund API is enabled you can issue the refund directly through Odoo.

Configuration on Odoo

  1. Install the module from the Apps menu.
  2. Now, navigate to the Payment providers by going to:
    • Accounting ‣ Configuration ‣ Payment Providers
    • Website ‣ Configuration ‣ Payment Providers
    • Sales ‣ Configuration ‣ Payment Providers
  3. Select the provider and configure the Credentials tab.
  4. Set the State to Enabled.

After configuring the details, On your website checkout page, you will see the BillDesk payment methods (UPI, Card, Netbanking, etc.) based on the configuration you set in the Payment Provider.
